CLI to get dollar to peruvian sol exchange rate

Currently, it shows data from `rextie`, `kambista`, `tkambio`, `roblex`, `decamoney`, `tucambista`, `chapacambio`, `cambiomundial`, and `sunat`.

## Install

    npm install -g dollarpe

## Usage

    dollarpe
